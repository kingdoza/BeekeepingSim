# Beekeeping Tech Progression Plan

## 문서 목적

이 문서는 조선시대 배경 전환에 맞춘 초반-중반-후반 양봉 방식 기획 초안이다.

이 문서는 독립적인 기획 문서이며, 현재 아키텍처 정본 문서를 대체하지 않는다. C++ 구조, Blueprint API, Core Redirect, 시스템 책임 변경은 이 문서에서 확정하지 않는다.

## 기본 전제

- 세계관 내 사육 벌은 토종벌만 사용한다.
- 후반의 현대식 양봉도 서양종 전환이 아니라 토종벌 양봉의 현대화로 본다.
- 테크 전환은 기존 벌통 개조가 아니라 분봉/이주를 통해 다음 단계 벌통에 새 군락을 들이는 방식이다.
- 단계별 차이는 벌 종류보다 벌통 구조, 관측 정확도, 작업 단위, 벌집 손상률, 반복 생산성에서 발생한다.

## 단계 요약

```text
초반: 누운 반통 통벌통
중반: 계상식 토종벌통
후반: 토종벌 현대식 소비장 벌통
```

핵심 관리 단위:

```text
초반: 벌집 1장 단위 획득
중반: 층/단 단위 확장, 확인, 채밀
후반: 소비장/프레임 단위 관리 후 재사용
```

## 현재 벌통 스탯과의 대응

현재 구현된 벌통 스탯은 세 단계 모두의 기반값으로 재사용할 수 있다. 단계별 차이는 해당 스탯을 얼마나 정확히 보여주고, 어떤 상호작용으로 조작할 수 있는지에서 만든다.

| 현재 스탯/개념 | 기획상 의미 |
|---|---|
| `ColonyBeeCount` | 군세 |
| `CurrentCombCount`, `MaxCombCount` | 내부 벌집/공간 수용량 |
| 소비장별 `HoneyAmount` | 벌집 또는 단별 꿀 저장량 |
| 소비장별 `HoneyRipeness` | 꿀 숙성도 |
| `bHasQueenBee` | 여왕벌 존재 여부 |
| `SwarmingPressure` | 분봉압 |
| 왕대 수 | 분봉 임박 신호 |
| `SanitationValue`, disease ratio | 위생, 질병 위험 |
| `AggressionValue` | 벌의 공격성 |
| 화분떡/급이 보너스 | 산란 보조, 군세 회복 보조 |

## 초반: 누운 반통 통벌통

### 구조

- 속을 파낸 통나무를 세로로 반 갈라 눕혀 사용한다.
- 아래쪽 통나무는 본체, 위쪽 통나무는 뚜껑 역할을 한다.
- 자연 벌집은 본체 쪽에 달린다.
- 여러 장의 자연 벌집이 세워진 상태로 횡방향 배치된다.
- 뚜껑을 열어 내부 확인이 가능하다.

### 관리 단위

- 채밀 단위는 자연 벌집 1장이다.
- 벌집은 후반 소비장처럼 재사용 가능한 프레임이 아니라, 본체에 달린 자연 벌집이다.
- 벌집 1장을 획득하면 해당 벌집의 꿀, 밀랍, 육아부, 저장 공간이 함께 손상되거나 제거된다.

### 주요 상호작용

| 상호작용 | 목적 | 영향 |
|---|---|---|
| 뚜껑 열기 | 내부 확인 | 공격성 증가, 장시간 개방 시 온도/안정성 손실 |
| 벌집 살피기 | 벌집별 꿀/숙성/육아부 상태 확인 | 초반치고는 직접 확인 가능하지만 세부 수치는 거칠게 표시 |
| 연기 넣기 | 공격성 낮추기 | 과사용 시 군세/생산성 패널티 가능 |
| 벌집 1장 베기 | 꿀벌집 획득 | 꿀과 밀랍 획득, 벌집 수용량과 군세 안정성 감소 |
| 빈 통벌통 놓기 | 자연 분봉 유도 | 분봉 손실을 새 군락 획득 기회로 전환 |
| 틈 메우기 | 보온/방수/위생 보조 | 환기 저하 위험 |
| 비가림 얹기 | 습기 피해 감소 | 위생/질병 위험 완화 |
| 짚 보온 | 겨울 생존 보조 | 겨울 감소량 완화 |
| 소문 좁히기 | 말벌/도둑벌 방어 | 과하면 채집 효율 저하 |

### 생산성 특징

- 채밀 시 벌집 자체를 제거하므로 회복 시간이 길다.
- 꿀 수확량은 낮지만 밀랍 부산물이 많다.
- 벌집을 너무 많이 베면 월동 실패, 군세 약화, 분봉/도망 위험이 커진다.
- 생산성은 낮고 위험은 높지만 초기 제작 비용이 낮다.

### 권장 표시 방식

초반에는 숫자보다 상태 문구 중심이 어울린다.

```text
군세: 약함 / 보통 / 왕성함
꿀: 적음 / 찼음 / 무거움
숙성: 묽음 / 익어감 / 잘 익음
위생: 깨끗함 / 습함 / 나쁨
분봉 기미: 없음 / 소란 / 뭉침
```

## 중반: 계상식 토종벌통

### 구조

- 직육면체 나무틀이 층층이 탑처럼 쌓인 벌통이다.
- 각 층은 게임플레이 단위가 된다.
- 단 내부의 벌집은 자연 벌집이며 고정식이다.
- 후반처럼 소비장/프레임을 한 장씩 빼서 관리하지 않는다.
- 상단 단은 주로 꿀 저장 공간, 하단 단은 군세/육아 공간으로 쓰는 방향이 적합하다.

### 관리 단위

- 층/단 단위로 확장, 확인, 채밀한다.
- 상단 단을 떼어 채밀하면 하단 육아부 손상을 줄일 수 있다.
- 빈 단 추가로 내부 공간을 늘려 분봉압을 낮출 수 있다.

### 주요 상호작용

| 상호작용 | 목적 | 영향 |
|---|---|---|
| 상단 확인 | 꿀 저장량/숙성 확인 | 초반보다 관측 정확도 증가 |
| 단 추가 | 공간 확장 | 수용량 증가, 분봉압 감소 |
| 단 제거 | 겨울 대비 공간 축소 | 보온/방어 안정, 과하면 생산 공간 감소 |
| 상단 단 채밀 | 꿀단 수확 | 하단 육아부 피해 감소 |
| 유도초/묵은 밀랍 바르기 | 새 벌집 유도 | 단 정착 속도 증가 |
| 급이하기 | 군세 회복/산란 보조 | 산란 보너스, 자원 소비 |
| 바닥 청소 | 위생 개선 | 질병 위험 감소 |
| 오래된 벌집 정리 | 위생 개선 | 단기 생산량 감소 |
| 왕대 확인/제거 | 분봉압 관리 | 과도 제거 시 여왕 갱신 실패 위험 |
| 인공 분봉 | 새 군락 확보 | 원 벌통 군세 감소, 새 벌통 생성 |
| 약군 합치기 | 약한 군락 회복 | 여왕/군세 정책 필요 |

### 생산성 특징

- 초반보다 내부 공간을 확장할 수 있어 군세 상한이 높다.
- 상단 단 채밀로 육아부 손상을 줄여 회복이 빠르다.
- 분봉압을 단 추가/인공 분봉으로 관리할 수 있어 군세 손실을 줄인다.
- 후반보다는 벌집 재사용성과 정밀 관리가 낮다.

### 권장 표시 방식

중반은 초반보다 세분화된 정보를 보여줘도 된다.

```text
각 단 상태: 빈 단 / 벌집 조성 중 / 육아 중심 / 꿀 저장 중 / 채밀 가능
단별 꿀: 낮음 / 중간 / 높음
단별 숙성: 미숙 / 숙성 중 / 숙성 완료
분봉압: 낮음 / 주의 / 높음
```

## 후반: 토종벌 현대식 소비장 벌통

### 구조

- 토종벌을 현대식 소비장/프레임 벌통으로 사육한다.
- 현재 구현된 현대 양봉 작업 흐름이 이 단계에 해당한다.
- 벌통 내부는 소비장 단위로 확인, 회수, 작업대 처리, 재배치가 가능하다.

### 관리 단위

- 소비장/프레임 1장 단위로 관리한다.
- 소비장은 꿀 양, 숙성도, 밀개 상태, 벌 부착, 여왕벌 부착, 왕대 상태를 개별 상태로 가진다.
- 밀개 제거 후 꿀만 추출하고 소비장을 재사용할 수 있다.

### 주요 상호작용

| 상호작용 | 목적 | 영향 |
|---|---|---|
| 뚜껑 열기 | 내부 접근 | 후속 소비장 작업 가능 |
| 소비장 들기/내리기 | 개별 상태 확인 | 벌집 단위 정밀 관리 |
| 벌솔 사용 | 벌 제거 | 소비장 회수 조건 만족 |
| 훈연기 사용 | 공격성 감소 | 작업 안정성 증가 |
| 소독약 사용 | 위생 증가 | 질병 위험 감소 |
| 왕대 제거 | 분봉압 감소 | 분봉 관리 |
| 왕롱 사용 | 여왕벌 포획 | 여왕 상태 이전/관리 |
| 벌 운반통 사용 | 분봉 본진 벌 포획 | 분봉을 자산화 |
| 밀도 작업대 사용 | 밀개 제거 | 채밀 준비 |
| 꿀 용기/소분대 사용 | 꿀 보관/혼합/소분 | 품질과 판매 단위 관리 |

### 생산성 특징

- 소비장 재사용으로 회복 시간이 가장 짧다.
- 꿀 생산, 숙성, 밀개, 채밀, 소분을 분리해 품질 관리가 가능하다.
- 작업 도구가 많아 벌통당 처리 시간이 줄어든다.
- 분봉과 여왕벌을 손실이 아니라 관리 가능한 자산으로 전환한다.

## 단계별 생산성 향상 축

| 향상 축 | 초반 | 중반 | 후반 |
|---|---|---|---|
| 관리 단위 | 벌집 1장 | 층/단 1개 | 소비장 1장 |
| 공간 확장 | 제한적 | 단 추가 가능 | 소비장/벌통 모듈 관리 |
| 채밀 손상 | 높음 | 중간 | 낮음 |
| 벌집 재사용 | 거의 없음 | 일부 제한 | 높음 |
| 관측 정확도 | 낮음-중간 | 중간 | 높음 |
| 분봉 관리 | 빈 통벌통 유도 | 단 추가/인공 분봉 | 왕대/왕롱/운반통 정밀 관리 |
| 위생 관리 | 외부 보수 중심 | 청소/정리 가능 | 소독/상태 관리 가능 |
| 품질 관리 | 거친 꿀 중심 | 숙성 판단 가능 | 숙성/밀도/소분 관리 |

## 테크 전환 방식

테크 전환은 벌통 자체를 업그레이드하지 않는다. 분봉이나 이주를 통해 다음 단계 벌통에 새 군락을 들인다.

```text
초반 통벌통 군세 성장
-> 분봉압 상승
-> 빈 중반 계상 벌통 설치
-> 분봉 유도 또는 이주 작업
-> 중반 벌통에 새 군락 정착
```

후반 전환도 같은 흐름을 따른다.

```text
중반 벌통 강군화
-> 후반 소비장 벌통 제작/설치
-> 분봉/이주로 새 군락 입주
-> 후반 정밀 관리 루프 시작
```

## 밸런스 방향

### 초반

- 제작 비용 낮음
- 수확량 낮음
- 벌집 손상 큼
- 실패 위험 큼
- 밀랍 부산물 많음
- 감각적 관리 중심

### 중반

- 제작 비용 중간
- 단 확장으로 군세 수용량 증가
- 상부 채밀로 육아부 손상 감소
- 분봉압 관리 가능
- 토종벌 양봉의 주력 생산 단계

### 후반

- 제작 비용 높음
- 작업 도구 의존도 높음
- 소비장 재사용으로 반복 생산성 높음
- 꿀 품질/숙성/소분 관리 가능
- 분봉과 여왕벌 관리가 가장 정밀함

## 구현 시 주의할 경계

- 초반 통벌통에 후반 소비장 lift/작업대 루프를 열지 않는다.
- 중반 계상 벌통은 층 단위 관리까지만 허용하고, 소비장 1장 단위 회수는 후반 전용으로 남긴다.
- 후반도 토종벌을 유지하므로 벌 종류 교체 보너스가 아니라 구조와 도구에 의한 생산성 향상으로 설계한다.
- 세 단계 모두 같은 벌통 스탯 모델을 공유하되, UI 표시 정확도와 사용 가능한 상호작용을 단계별로 제한한다.
- 분봉/이주는 테크 전환의 핵심 루프이므로 단순 버튼 업그레이드로 처리하지 않는다.
